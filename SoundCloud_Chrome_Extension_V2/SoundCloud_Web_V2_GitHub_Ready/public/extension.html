SoundCloud Downloader

Chrome extension

Download controls on SoundCloud pages, plus a toolbar popup.

Install

Download extension ZIP

Chrome only installs extensions directly from the Chrome Web Store after publication. For this development build:

  1. Download and unzip the extension package.
  2. Open chrome://extensions and enable Developer mode.
  3. Click Load unpacked and select the extension folder.
  4. Open the extension popup and enter this website's address and your access key.

A Chrome Web Store install link can replace this page after the extension is published.
